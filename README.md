I've been building products around large language models — not just calling an API, but designing the surrounding system: prompting, context, and agent orchestration.

- **[e3electricai](https://github.com/sourabh1428/e3electricai)** — AI-powered electric utility management dashboard with LLM-driven insights
- Integrating **Claude** and **OpenAI** APIs into production apps: structured output, tool calling, streaming

- Exploring agentic workflows — multi-step tool use, retrieval-augmented generation, and automation pipelines
